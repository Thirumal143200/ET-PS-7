# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |

## Reporting Vulnerabilities

Security vulnerabilities targeting Critical National Infrastructure telemetry or SOAR playbooks should be reported directly to:

- **Email**: `security@cni-cyber.gov.in`
- **Response SLA**: 24 hours

Please include a proof-of-concept log or API request header in your disclosure.
